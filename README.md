# git-practice

GitとGitHubの練習用リポジトリです。

## 学んだこと
- `git init`
  - フォルダをGitで管理開始する
- `git status`
  - 今の変更状態を確認する
- `git add`
  - 変更したファイルを次のcommit対象に入れる
- `git commit`
  - 変更をローカル履歴として保存する
- `git log`
  - commit履歴の一覧を見る
- `git diff`
  - どこが変わったか差分を見る
- `git branch`
  - branchの一覧確認や作成、削除を行う
- `git switch`
  - branchを切り替える
- `git merge`
  - 別branchの変更を今いるbranchに取り込む
- `.gitignore`
  - Gitで管理しないファイルやフォルダを指定する
- `git restore`
  - commit前の変更を元に戻す
- `git remote add origin`
  - GitHubリポジトリの接続先を登録する
- `git remote -v`
  - 今つながっているGitHubの接続先を確認する
- `git remote remove origin`
  - GitHubとの接続設定を解除する
- `git remote set-url origin`
  - 既存のGitHub接続先URLを別のものに変更する
- `git push -u origin main`
  - ローカルのmainをGitHubへ送り、以後の送り先として覚えさせる
- `git pull`
  - GitHubの最新状態をローカルへ取り込む
